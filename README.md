# Data Analytics Project

## Overview

This project demonstrates an end-to-end data analytics workflow, from data collection and preprocessing to visualization and reporting. The objective is to transform raw data into meaningful insights using industry-standard analytics tools and techniques.

The project covers:

* Data loading and preprocessing using Python
* Exploratory Data Analysis (EDA)
* Data cleaning and transformation
* SQL-based analysis using PostgreSQL, MySQL, and SQL Server
* Interactive dashboard development in Power BI
* Business report preparation
* Presentation creation using Gamma

---

## Dataset

The dataset contains structured data used for analysis and visualization. It was imported into Python for preprocessing and later stored in relational databases for SQL analysis.

**Dataset Features**

* Multiple attributes for analysis
* Missing and inconsistent values handled during preprocessing
* Suitable for business intelligence and visualization

## How to Run

### Prerequisites

Install the required Python packages:

```bash
pip install pandas numpy matplotlib seaborn
```

### Steps

1. Clone the repository.
2. Open the Python notebooks.
3. Load the dataset.
4. Run the EDA and data cleaning notebooks.
5. Import the cleaned data into PostgreSQL, MySQL, or SQL Server.
6. Execute the SQL queries.
7. Open the Power BI dashboard (`.pbix`) to explore the visualizations.
8. Review the project report and presentation for a summary of findings.
